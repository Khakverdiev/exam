Clothing Store

Clothing Store — это веб-приложение, позволяющее пользователям покупать одежду и оставлять отзывы о продуктах. Приложение включает следующие основные функции:

Основные функции:

Функции пользователя:

1. Просмотр и покупка различных видов одежды.
2. Возможность оставлять отзывы и оценивать товары.
3. Управление профилем пользователя.

Админ панель:
1. Добавление, редактирование и удаление продуктов.
2. Управление ролями пользователей (назначение ролей "пользователь" и "администратор").
3. Просмотр отзывов, оставленных пользователями.
4. Просмотр и управление заказами пользователей.

Используемые технологии:
1. Backend: ASP.NET Core для разработки API и управления данными.
2. Frontend: React с использованием Tailwind CSS для стилизации и создания отзывчивого интерфейса.
3. База данных: SQL Server на удаленном сервере для хранения данных о пользователях, продуктах и заказах.
4. Аутентификация: JWT для безопасного управления сеансами и доступом.
5. Хранение изображений: Azure Blob Storage для хранения изображений продуктов.

Этот проект позволяет пользователям удобно и безопасно покупать одежду, оставлять отзывы, а администраторам управлять контентом и пользователями в системе.

Как использовать сайт:
После регистрации и входа на сайт пользователю необходимо выполнить несколько шагов для полного доступа к функциям:

1. Заполнение профиля пользователя:

Нажмите на своё имя пользователя в верхней части страницы, чтобы перейти в свой профиль (UserProfile).
Заполните все необходимые данные, такие как имя, фамилия, адрес и другие контактные данные.

2. Подтверждение Email:

После заполнения данных в профиле вам нужно подтвердить свою электронную почту.
Подтверждение электронной почты необходимо для того, чтобы иметь возможность оставлять отзывы о продуктах.

3. Изменение пароля (по желанию):

Если вы хотите изменить пароль, вы можете сделать это в профиле, следуя инструкциям на странице.

После выполнения этих шагов вы получите полный доступ ко всем возможностям сайта, включая возможность оставлять отзывы о продуктах, которые вы приобретаете. 
Подтверждение Email является важным шагом для безопасности и для активации функции оставления отзывов.
